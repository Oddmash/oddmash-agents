# Oddmash Agents

Follow the organization working agreements in `Oddmash/.github/AGENTS.md` and `docs/AI-CODE-REVIEW.md`.

The reviewer is advisory. Never approve, request changes, merge, publish, deploy, execute contributed code, or access repository secrets. Default to report-only, public opt-in repositories, bounded requests, and synthetic test fixtures. Use trusted base-branch guidance, validate all model output, and never include exploit instructions or private values in reports.

Keep tests offline and deterministic. Run `npm test` before delivery.

# Operator runtime controls

The authenticated owner can restrict optional coordinated specialist work from Settings. The saved controls apply to future coordinated runs, not work already in progress. The deployment-authorized configuration remains the maximum: restore defaults removes restrictions, so the worker uses the current deployment baseline, not fixed model or budget values.

The operator can pause optional coordinated specialists, exclude individual optional roles, and lower request and time limits. Lead review, authorization, repository enrollment, model selection, review and merge protection, and application credentials remain outside this editor.

The console uses the private operator contract package entrypoint. Worker and server imports use the established internal TypeScript source tracing convention for Vercel. The same server-side store configuration is reused for read and write; the browser receives no credential. The write route requires the configured owner session and canonical same-origin JSON. An atomic revision comparison prevents lost updates and records the latest 50 nonsecret audit entries. A conflict preserves the draft and requires an explicit revision reload before retry.

# Contributor PRs

The owner-only console includes Contributor PRs for open public Oddmash pull requests. GitHub author association and user type distinguish external contributors from bots, members and collaborators; the configured owner is excluded by stable ID. Results are bounded to the 100 most recently updated public PRs before classification. A partial result is marked when the public search reports truncation or incomplete results. Refresh explicitly to check a new snapshot; results can be cached for up to 60 seconds per instance.

The PR card shows repository, author, title, update time, reported draft status, and retained agent observations. Missing telemetry is not an assertion about review or CI. Follow the PR and Checks links for current GitHub state. No private PRs, new credentials, approval, or merge authority are introduced.

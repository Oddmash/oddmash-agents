# Contributor PRs

The owner-only console includes open public Oddmash pull requests by external contributors. GitHub author association and user type distinguish external contributors from bots, members and collaborators; the configured owner is excluded by stable ID. Search is bounded to the 100 most recently updated public PRs before classification. Partial search results are labelled.

Each card shows repository, author, title, update time and draft status, separately from GitHub formal reviews, workflow observations and retained execution telemetry. On the four most recently updated external results, three additional public reads resolve the current PR head, verified Oddmash bot reviews (by stable account ID), and matching PR workflow runs for that head. Review badges distinguish older revisions; a review is not a merge eligibility decision. The review page is capped at 100 chronological entries; incomplete evidence is labelled. The remaining cards show unavailable evidence.

Workflow action-required and waiting states are shown only when GitHub reports them. A fork run may lack a PR association; match its exact source repository, branch and head revision against the PR. Action-required may mean workflow approval or another manual action; the console links to GitHub for inspection rather than assuming the cause. Missing runs or failed reads are unknown, not evidence of successful checks or no review. A workflow failure badge is an observed run result, not the required-check aggregate.

A 15-minute instance cache and four-card detail bound limit anonymous requests to at most 13 per snapshot (52 per uninterrupted hour per instance); shared provider IP quotas may still lead to unavailable evidence. All provider requests are public, fixed-origin, read-only and timeout-bounded. Refresh reuses cached evidence until expiration. No new credentials, approval, workflow execution, or merge authority is introduced.
